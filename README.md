# Calorie Counter — Счетчик калорий

Консольное приложение на Kotlin для подсчёта шагов, калорий и статистики за месяц с поддержкой целей и расчётом дистанции.

**Основная логика:** ввод шагов → подсчёт статистики → конвертация в км и ккал → вывод лучшей серии

---

## Технологический стек

| Категория | Технологии |
|-----------|------------|
| **Язык** | Kotlin 1.9.20 |
| **Парадигма** | ООП, функциональный стиль |
| **Коллекции** | `List`, `MutableList`, `Map` |
| **Функции** | `map`, `filter`, `sum`, `maxOrNull`, `average`, `forEachIndexed` |
| **Enum** | `MenuCommand` |
| **Тестирование** | JUnit 5 |
| **Сборка** | Gradle (Kotlin DSL) |
| **IDE** | IntelliJ IDEA |

---

## Классы

| Класс | Роль | Основная задача |
|-------|------|-----------------|
| **Main** | Точка входа | Цикл меню, обработка команд |
| **SleepTracker** | Управление месяцами | Массив из 12 месяцев, статистика |
| **MonthData** | Данные за месяц | Хранение шагов (30 дней), расчёты |
| **Converter** | Конвертация | Шаги → километры, шаги → калории |
| **MenuCommand** | Enum команд | Список команд меню |

---

## Функциональность

### Ввод данных
- Ввод шагов за определённый день месяца
- Изменение дневной цели по шагам (по умолчанию — 10 000)

### Статистика
- Количество шагов по дням
- Общее количество шагов за месяц
- Максимальное количество шагов
- Среднее количество шагов
- Пройденная дистанция (в км)
- Сожжённые калории (в ккал)
- Лучшая серия дней с достигнутой целью

### Выход
- Корректное завершение работы приложения
